## 관련 Issue

- #12 [FE] Mac에서 오프라인으로 녹음하고 계정별 원본을 잠금·복구

## 한 줄 요약

Mac 개인 녹음은 기기에 보관하고 로그아웃 시 잠근다. 같은 계정으로 다시 열며 기기 삭제는 별도로 수행한다.

## 왜 이 결정이 필요했나

웹 세션과 조각 업로드에 의존하면 네트워크가 없는 Mac에서 회의를 녹음하고 다시 열 수 없다.

원본만 Mac에 두고 문서를 서버와 동기화하는 안을 검토한 뒤, 개인 회의 기록의 보관과 접근 범위를 다시 정했다.

결정 동인:

- 개인 데이터 통제, 오프라인 녹음 복구, 계정 전환 뒤의 접근 격리

## 트레이드 오프

- 서버 업로드와 저장을 재사용하면 웹과 기록을 공유할 수 있지만 오프라인에서 서버 없이 완료하기 어렵다.
- 원본은 로컬에 두고 문서를 서버와 동기화하면 다른 기기에서 문서를 볼 수 있지만 회의 내용이 서버에 남는다.
- 원본과 문서를 Mac에 보관하면 다른 기기로 자동 복사되지 않으며 사용자가 기기의 보관 및 삭제를 통제한다.

## 무엇을 결정했나

Mac 개인 녹음은 기기에 보관하고 로그아웃 시 잠근다. 같은 계정으로 다시 열며 기기 삭제는 별도로 수행한다.

회의 내용의 서버 전송을 줄이고, 오프라인 재실행과 공유 Mac에서의 계정별 보관을 함께 보장한다.

## 결과

- 기기마다 원본 목록이 다르다.
- 기기에서 삭제한 원본은 서버를 통해 복구할 수 없다.

## 다시 논의해야 할 조건

- 사용자가 여러 기기 간 백업 또는 동기화를 요구할 때
