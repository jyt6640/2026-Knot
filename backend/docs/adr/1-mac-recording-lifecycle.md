# 창 닫기에는 녹음을 유지하고 앱 종료는 저장 확인 뒤 처리

## 상태

Proposed

## 관련 Issue

- #1 [FE] Mac 본창에서 웹 녹음·문서 흐름을 공유하고 안전하게 종료

## 한 줄 요약

창 닫기에는 녹음을 유지하고 앱 종료는 저장 확인 뒤 처리

## 왜 이 결정이 필요했나

Mac 본창은 웹과 같은 React 홈·녹음·문서를 사용한다. 빨간 닫기 버튼은 창만 숨긴다. 녹음·일시정지 상태에서 ⌘Q는 확인을 띄우고, 계속 녹음을 선택하면 기존 상태로 돌아간다. 녹음 끝내고 종료를 선택하면 마지막 조각의 서버 저장을 확인한 뒤 종료한다.

녹음 중 본창을 닫거나 ⌘Q를 누를 때 서버가 녹음 종료를 받아도 마지막 오디오 조각은 전송 중일 수 있다.

결정 동인:

- 창을 숨기고 다른 앱을 써도 발화를 잃지 않으며, 사용자가 끝낸 경우에만 종료하기 위해

## 트레이드 오프

- 창 닫을 때 녹음 유지
- 끝내기 확인

## 무엇을 결정했나

## 결과

- 서버 종료 응답과 오디오 저장 성공을 구분한다. 이미 업로드 중이면 새 종료 요청 없이 기다린다. 실패하면 앱과 임시 조각을 유지하고 재시도를 제공한다. 기존 서버 저장·전사 방식을 사용한다.

## 다시 논의해야 할 조건

- 녹음 소유권 또는 오디오 저장 정책 변경
