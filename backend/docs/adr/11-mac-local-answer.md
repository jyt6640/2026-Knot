# Mac의 명시적인 AI 답변 요청을 전용 무저장 POST API로 처리한다.

## 상태

Proposed

## 관련 Issue

- #11 [BE] Mac 개인 탐색의 로컬 발췌 기반 무저장 AI 답변 API

## 한 줄 요약

Mac의 명시적인 AI 답변 요청을 전용 무저장 POST API로 처리한다.

## 왜 이 결정이 필요했나

Mac의 개인 문서와 색인은 로컬에 보관한다.

웹 탐색 API는 접수 시 질문과 답변을 대화에 영속화한다.

결정 동인:

- 개인 질문과 로컬 발췌를 서버 이력에 남기지 않고 답변을 받아야 한다.
- 로컬 자료의 보관 경계를 지키고 웹의 기존 대화 저장을 유지한다.

## 트레이드 오프

- 기존 웹 대화 API 재사용은 이력 저장과 서버 검색을 수반한다.
- 전용 무저장 API는 입력을 발췌로 제한하고 현재 요청에만 응답한다.

## 무엇을 결정했나

Mac의 명시적인 AI 답변 요청을 전용 무저장 POST API로 처리한다.

로컬 자료의 보관 경계를 지키고 웹의 기존 대화 저장을 유지한다.

## 결과

- 클라이언트는 문단 번호를 로컬 데이터에 대응한다.

## 다시 논의해야 할 조건

- 사용자가 개인 대화의 기기 간 동기화를 선택할 때
